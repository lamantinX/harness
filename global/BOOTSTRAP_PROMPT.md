# Bootstrap Prompt

Before working, follow the Global Agent Protocol.

Read:

1. Global protocol if accessible: `~/.ai-harness/GLOBAL_AGENT_PROTOCOL.md`.
2. Project `AGENTS.md` if present.
3. Project-specific harness docs only as needed.

Do not start by scanning the whole repository.

First response should include:

- detected project;
- task classification;
- context budget;
- whether this requires plan/approval;
- files/docs you intend to inspect first.

For Complex/Core-risk tasks:

- plan only first;
- wait for user approval;
- execute only after approval.
