# Run Logging Skill

Append a concise record to `docs/ai-runs/` when present, otherwise use the global fallback log.

Include:
- date
- project
- agent/tool
- model
- task
- task class
- risk tier
- plan used
- approval
- files inspected
- files changed
- checks run
- result
- context notes
- harness note
