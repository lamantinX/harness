# Task Routing

## Trivial
No heavy plan. Minimal context.

## Standard
Small plan, focused context, small diff, targeted verification, run log.

## Complex
Plan first. User approval required. Execute approved plan only.

## Core-risk
Plan first. User approval required. Add security/evaluator checks where available.

## Research-only
No edits. Findings only.

## Meta-harness improvement
Inspect logs, propose one small improvement, get approval, compare.
